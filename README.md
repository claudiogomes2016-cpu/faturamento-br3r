# Automação do Faturamento — BR3R

Ferramenta em HTML único (abre direto no navegador, sem instalação) para apoiar o faturamento da Ball Três Rios:

- Leitura de planilhas `.xlsx` / `.csv` no próprio navegador, com identificação automática do tipo de arquivo
- Grade operacional de OVs / itens com filtros, KPIs, estoque e cálculo de volume
- Montagem de carga por veículo e alertas
- Tela "Conferir antes de gravar"
- Geração da ficha FO-TR-074 (Ficha de Montagem de Carga) e lista de motoristas

## Como usar

Abra o `index.html` no navegador.
